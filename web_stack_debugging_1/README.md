# Web Stack Debugging #1

This project focuses on debugging an Ubuntu container to configure Nginx to listen on port 80 on all active IPv4 interfaces.

## 0. Nginx likes port 80

The script `0-nginx_likes_port_80` fixes the enabled Nginx site configuration and starts Nginx.

## 1. Make it sweet and short

The script `1-debugging_made_short` applies the same fix in a short Bash script of five lines or fewer.
